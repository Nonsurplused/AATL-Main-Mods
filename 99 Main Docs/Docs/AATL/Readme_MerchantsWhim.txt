A Merchant's Whim

By PikachunoTM


Requires: 
Latest AATL_Data (https://www.nexusmods.com/morrowind/mods/50647)
Latest OAAB_Data (https://www.nexusmods.com/morrowind/mods/49042)


Description:
A new merchant in Vivec has had a change of heart, and would like your help with a personal matter of his.


Compatibility:
May be slightly incompatible with locations that affect the Vivec, Foreign Quarter (3, -10). Note, nothing has been moved or touched in vanilla, so theoretically it should be fully compatible, with at some clipping. Vanilla is touched as little as possible.


Permissions:
Refer to the requirements' mod pages for perms. This esp can be fully translated, edited, done whatever with that doesn't conflict with Bethesda's constrictions.
