Dim's Ring of Khajiit Replacer
By DimNussens

Version: 1

Requires: Base Morrowind.


---------
Changelog
---------

1.0: Initial release.



------------
Description
------------

This is a simple Skyrim-inspired model replacer to make the Ring of Khajiit visually unique. The replacer only affects the Ring of Khajiit -- it does not affect other rings using the original model, such as the Ring of Surroundings.



-------------
Compatibility
-------------

The ESP directly modifies the Ring of Khajiit, swapping out the file paths to my custom ones. Any other mod that affects the Ring of Khajiit might undo my changes. 



--------
Install
--------

Unzip in your Data Folder or use your prefered mod installer.
